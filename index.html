🔢 KNN Face Vector Visualizer
How KNN Works in VisionVote

Each registered face is encoded as a 128-dimensional vector. During verification, the system computes the Euclidean distance between the live face vector and all stored vectors. If the nearest neighbour distance is below 0.55, it's a match. Below is a 2D PCA projection of all face vectors — voters with faces registered appear as coloured clusters. The further apart the dots, the easier it is for KNN to tell them apart.
